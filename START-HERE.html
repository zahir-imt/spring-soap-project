StockBridge, entirely online.

No Java, Maven, Docker or GitHub Desktop installation is needed on your Mac. The application and tools run in GitHub Codespaces.

Open your prepared workspace

Open the online editor while signed in to your GitHub account. Reuse this workspace instead of creating a new one each time.

  1. Open Terminal in the browser editor.
  2. Run bash scripts/run-online.sh.
  3. Open the Ports tab and choose Open in Browser for port 8080.
  4. Keep port visibility Private. Use the GitHub-generated preview address, not localhost on your Mac.

Test it

Stop the app with Control+C, then run:

bash mvnw --batch-mode clean verify

All 19 tests passed in the verified cloud run. Start the app again afterwards.

When you finish

Save and push code changes, then use GitHub Codespaces → … → Stop codespace. Closing a browser tab alone does not stop it. Included usage is limited; check your account allowance.
